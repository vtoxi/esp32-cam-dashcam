# RCWL-0516 Motion Sensor — Wiring

**Status: Pinout confirmed from photo; ESP32-CAM-side GPIO still TBD.** Physical unit's
header is confirmed silkscreened `CDS VIN OUT GND 3V3` (5 pads, in that left-to-right
order on the board photographed). The `CDS` pad is a light-sensor (photoresistor) input
found on some RCWL-0516 clones, used to disable triggering in daylight — not required for
basic motion sensing and left unconnected unless that feature is used. Which ESP32-CAM
GPIO the `OUT` pin connects to is still pending Phase 3 (see
`docs/wiring/ESP32_CAM.md` Section 3 and `docs/HARDWARE.md` GPIO Conflicts).

Dozens of these units are on hand, but not every camera node necessarily gets one — which
nodes are deployed with motion sensing is a Phase 6 deployment decision, not a supply
constraint. Wiring below applies identically to any unit used.

## 1. Module Description

RCWL-0516 microwave (Doppler radar) motion sensor. Outputs a digital HIGH pulse when
motion is detected within range (~5–7m typical, adjustable only on some variants via an
onboard potentiometer/resistor pad — verify against the physical unit).

## 2. Voltage Requirements

- Input (VIN): 4V–28V DC (commonly powered from 5V rail).
- Output (OUT): 3.3V logic level (most RCWL-0516 breakouts have an onboard 3.3V
  regulator feeding a 3.3V output pin — verify, since directly connecting a 5V-logic
  output to an ESP32 GPIO would be unsafe).

## 3. Pin Table (confirmed from physical unit)

| Pin | Connects to |
|---|---|
| CDS | Not connected (optional daylight-disable photoresistor input — unused) |
| VIN | 5V rail |
| OUT | ESP32-CAM free GPIO — **TBD**, see Phase 3 |
| GND | Common ground |
| 3V3 | Not required for this wiring; available if a downstream 3.3V load is needed |

## 5–6. Power / Ground

VIN to 5V rail, GND common with ESP32-CAM.

## 7. Communication Interface

Simple digital GPIO input (no bus protocol).

## 8. Pull-ups / Pull-downs

None required — RCWL-0516 output is actively driven.

## 9. Known Conflicts

Whichever GPIO is chosen must not collide with camera/SD pins — see
`docs/wiring/ESP32_CAM.md`.

## 10. Safety Warnings

Confirm OUT pin is genuinely 3.3V logic on the specific breakout before connecting
directly to an ESP32 GPIO.

## 11. Testing Procedure

1. Power module, verify onboard LED (if present) toggles on motion.
2. Read GPIO state in a minimal test sketch, confirm HIGH pulse on motion, LOW at rest.
3. Measure retrigger/cooldown behavior of the specific unit (varies by clone) before
   tuning `cooldownSeconds` in software (Section 17 of project spec).

## 13. Board-Specific Differences

Some RCWL-0516 clones have a solder pad (`C-TM`) affecting retrigger interval, and a
resistor pad affecting sensitivity — inspect the specific unit if tuning is needed.
