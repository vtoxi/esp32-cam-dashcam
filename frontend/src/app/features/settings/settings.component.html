About this console

This is a reference operator console for the CarSentinel remote backend (Phase 21 of the project specification) — it reads devices, telemetry, events, and incidents; issues remote commands; and manages webhook subscriptions. It never talks to a gateway or node directly — everything goes through the backend's REST API and Server-Sent Events stream. Device registration, heartbeats, telemetry ingestion, and evidence upload are all firmware-initiated and not performed from this console.
